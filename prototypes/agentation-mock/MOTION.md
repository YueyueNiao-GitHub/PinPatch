# Agentation Mock 动效规范

## 动效概念

- 产品：面向智能体的网页可视化标注工具
- 性格：精准、流畅、克制
- 用户任务：快速进入标注、定位对象、编辑反馈，并保持对当前状态的清晰理解
- 签名动效：右下角工具条以右侧主按钮为固定锚点，在圆形与胶囊之间连续形变；图标在容器形变中短暂模糊并显现/退场
- 无动效区域：文本输入、滑杆连续调整、页面滚动、键盘高频操作

## 原则

1. 状态来源清楚：弹窗、菜单和提示从触发点附近出现。
2. 高频操作快速：按钮反馈 100–150ms，菜单与提示 150–180ms，容器形变不超过 280ms。
3. 保持空间连续：工具条右侧锚点、主按钮尺寸、角标位置在展开与收起时保持稳定。
4. 退出更短：弹窗、面板和 Toast 的退场约为入场时长的 70%。
5. 动效不改变 UI：不通过动效修改布局结果、尺寸规范、颜色或信息层级。

## 动效地图

| 场景 | 目的 | 行为 | 减少动态效果 |
| --- | --- | --- | --- |
| 工具条展开/收起 | 解释模式切换 | 右侧锚定的宽度形变，图标轻微模糊交叉显隐 | 即时切换最终状态 |
| 标注弹窗 | 从点击目标进入编辑 | 从顶部触发边缘轻微位移与缩放进入，短退场 | 直接显示/隐藏 |
| 下拉与颜色面板 | 保持触发关系 | 按上下空间设置 transform-origin，轻微缩放与透明度进入 | 直接显示/隐藏 |
| 评论面板与示例弹窗 | 进入聚焦层 | 容器级单次进入，退出更短 | 直接显示/隐藏 |
| 标注气泡 | 标识新对象和编辑意图 | 仅首次创建时进入；悬停数字与编辑图标交叉显隐 | 即时图标切换 |
| Toast | 确认操作结果 | 短距离上移进入、短距离下移退出 | 直接显示/隐藏 |

## 工具条状态链

| 起点 | 事件 | 终点 | 动效 | 中断行为 |
| --- | --- | --- | --- | --- |
| 收起 | 点击 | 展开 | 胶囊向左扩展；固定尺寸图标组同步从 `scale(.42) + blur(10px)` 恢复 | 再次点击从当前计算值反向 |
| 展开 | 点击 | 收起 | 图标组整体压缩模糊，胶囊沿相同曲线向右收拢 | 再次点击从当前计算值反向 |
| 任意 | 打开标注弹窗 | 隐藏 | 轻微下移淡出 | 弹窗关闭后恢复最终状态 |
| 任意 | 减少动态效果 | 对应终态 | 无空间移动 | 状态含义保持不变 |

## 组件模式

### 按钮

- 按下反馈使用 `scale(0.97)`，90–120ms。
- 不移动悬停命中区域；悬停优先使用颜色和子图层变化。

### 工具条共享对象

- 右边缘和 44px 主按钮始终固定。
- 只允许外层胶囊执行 `44px -> 242px` 的宽度变化，时长 400ms。
- 五个操作和分割线保持固定自然宽度，只整体动画 `transform / filter / opacity`。
- 图标组与容器在同一帧启动，禁止再为子项增加 width、flex-basis 或分散延迟。
- 使用 `--ease-toolbar` 获得高初速度、长尾减速；快速反转依赖同一组 CSS transition 连续插值。

### 菜单和 Popover

- `transform-origin` 跟随触发点及展开方向。
- 入场使用 `opacity + scale(0.97) + 2px blur`，不做菜单项逐个 stagger。

### 弹窗和面板

- 容器只做一次结构动画，内容不重复位移。
- 入场 220–240ms，退出 130–170ms。
- 样式详情与可视化配置使用实测内容高度过渡，支持快速反转和互相切换，不直接跳变 `hidden`。

### 标注与反馈

- 已存在的标注不因普通重渲染重复播放入场动画。
- 连续输入、颜色滑杆和拖拽不添加缓动，确保跟手。

## 工具与约束

- 使用 CSS transitions/keyframes 与原生 WAAPI。
- 不增加 Motion、GSAP 等运行时依赖。
- 仅对小型浮层使用不超过 `4px` 的短暂 blur。
- 工具条宽度动画是经过约束的小型签名形变；其他区域优先只动画 transform/opacity。
